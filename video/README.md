# Explainer video

The code here builds `ring_camera_wedge_explainer.mp4`, a walkthrough of this repo, and `SCRIPT.md` is its script. The MP4 isn't committed, because it's meant to be uploaded to GitHub through the web editor. The whole video is generated by the code in this folder, using the repo's own scripts and STLs. To change the words, edit `narration.json` and rebuild; the picture follows the new timing.

The video is silent, with the narration shown as captions in the picture, because GitHub allows only 10 MB per uploaded video on a free plan. It's 720p at 24 frames per second for the same reason. `python video/encode.py --voiced` makes a 1080p version with voice, music and effects at `video/build/ring_camera_wedge_explainer_voiced.mp4`, which is about 44 MB.

| File | Purpose |
|---|---|
| `narration.json` | The script: every spoken line, its caption and its sound effects |
| `SCRIPT.md` | Readable copy of the script with its timings, generated from `narration.json` |
| `build_assets.py` | Exports the meshes and facts the video shows, and checks them against the committed STLs |
| `make_audio.py` | Generates the voice, music and sound effects, and works out the timing, which the silent version still follows |
| `scene/` | The 3D scenes and on-screen panels (Three.js) |
| `render.mjs` | Renders the frames in headless Microsoft Edge |
| `encode.py` | Joins the frames into the MP4, with audio if you ask for it |

## Rebuild

This needs Windows with Microsoft Edge, Node.js and Python 3.12. The renderer drives the Windows browser, so it can't run in the dev container. The repo's root `.venv` is also unusable here if it was created in the dev container, so this folder has its own virtual environment.

Run this once, from the repo root:

```powershell
python -m venv video\.venv
video\.venv\Scripts\python -m pip install -r requirements.txt -r video\requirements.txt
cd video
npm install
cd ..
New-Item -ItemType Directory -Force video\build\voice
Invoke-WebRequest https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/en/en_US/ryan/high/en_US-ryan-high.onnx -OutFile video\build\voice\en_US-ryan-high.onnx
Invoke-WebRequest https://huggingface.co/rhasspy/piper-voices/resolve/v1.0.0/en/en_US/ryan/high/en_US-ryan-high.onnx.json -OutFile video\build\voice\en_US-ryan-high.onnx.json
```

Then build the video:

```powershell
video\.venv\Scripts\python video\build_assets.py
video\.venv\Scripts\python video\make_audio.py
cd video
node render.mjs --clean
cd ..
video\.venv\Scripts\python video\encode.py
```

To check a few moments without rendering everything, run `node render.mjs --stills 12.5,40,90` from `video\`. The images appear in `video\build\stills`, named by their time in seconds.

`build_assets.py` stops with an error if the code no longer produces the committed STLs. If that happens, regenerate the STLs first.

## What's real and what's illustrative

- **From the repo:** the sketch, source code, terminal commands and their output, run times, STL bytes, triangle counts, file list, commit history and all printed parts. The cutters in the carving scene are captured from the boolean call in `build()`.
- **Illustrative:** the stand-in camera, its field of view, the seals' fly-in, the rain and water drops, the screws and nut, the screwdriver and the print animation. The tooth diagram uses the script's real dimensions, but it's flattened and enlarged.
